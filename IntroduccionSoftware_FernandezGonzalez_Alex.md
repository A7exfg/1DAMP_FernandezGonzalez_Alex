# **Introducción al Software**



## **¿Qué es un programa informático?**



Es el conjunto de instrucciones que se le da a cualquier dispositivo electrónico para que realice una tarea determinada.



## Diferencia entre código fuente, código objeto y código ejecutable:



Un código fuente es el programa escrito en código Java o Python. El código objeto es el resultado de compilar el código fuente.

Y el código ejecutable es el programa final listo para ejecutarse.



## Etapas del desarrollo del software:



1. Análisis: se estudian las necesidades del cliente.
2. Diseño: se planifica como va ser el programa.
3. Desarrollo o programación: se escribe el código fuente.
4. Pruebas: Se comprueba el funcionamiento y se corrigen errores.
5. Implantación: Se pone el programa en funcionamiento.
6. Mantenimiento: Se realizan mejoras y solucionan problemas.
